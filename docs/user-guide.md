# 素见 · 使用手册

素见是一个局域网内的内容社区，支持图文/视频笔记、点赞收藏评论、好友、私信、管理后台等功能。本手册只讲**怎么用**，不讲技术实现。

---

## 一、快速开始

### 1. 启动服务

在项目根目录打开终端，执行：

```bash
./start.sh          # 启动（自动编译 + 后台常驻，关闭终端不影响）
./start.sh stop     # 停止
./start.sh restart  # 重启
./start.sh status   # 查看运行状态
```

启动后控制台会打印访问地址：

```
素见已启动 ✓
  本机:   http://localhost:8099
  局域网: http://192.168.x.x:8099    ← 同一 WiFi/网线下的手机、电脑用这个打开
```

- **端口被占用**时：`PORT=9000 ./start.sh`（换成任意空闲端口）
- 日志写在 `data/sujian.log`，出问题可以先看它

### 2. 管理员账号

首次启动会自动创建管理员账号：**`admin` / `admin123`**

> 管理员初始密码可在 `main.go` 顶部修改后重新启动生效。建议首次登录后不要随意公开这个账号。

### 3. 想先看效果？生成演示数据

```bash
go run ./cmd/seed      # 已有数据时跳过
go run ./cmd/seed -f   # 强制清空后重建演示数据
```

会生成 3 个演示用户（密码均 `demo123`：苏小厨 / 阿梨 / 数码君）+ 若干带图笔记 + 评论/点赞/收藏/关注关系。

## 二、注册与登录

1. 打开首页 → 右上角「注册」
2. 填写**用户名（2-20 位）**、密码（至少 6 位）、昵称
3. 提交后状态为「**待审核**」——需要**管理员在管理后台通过**后才能登录
4. 通过后即可登录使用

> **忘记密码？** 找管理员：管理后台 → 用户管理 → 该用户「重置密码」或「重置为 000000」。

---

## 三、首页与信息流

- **频道 Tab**：顶部可切换「推荐 / 关注 / 分类频道（美食、旅行等）」
- **排序**：信息流右上可切「综合（热度）/ 最新」
- **为你推荐**：在「推荐」频道（综合排序、已登录）下，系统根据你的兴趣推荐内容——
  - 依据：你**点赞、收藏、评论、自己发布、关注的人**发布过的内容，提炼你的兴趣标签
  - 效果：你点赞越多同类型内容，这类内容越靠前
  - 新用户（没互动历史）自动按热度+新鲜度排序，不会空白
- **瀑布流**：卡片长短错落自动排列，图片加载、窗口缩放时自动重新排布；手机窄屏自动变 1~2 列

> **想让推荐更贴合兴趣？** 多点赞/收藏几篇你喜欢的内容，多给笔记打标签。

---

## 四、发布笔记

1. 首页右上角「发布」（或导航栏「+」）
2. 选择类型：**图文**（支持多张图片）或 **视频**
   - 图片：jpg/png/gif/webp，单张 ≤ 10MB（上传后会自动压缩，不用自己处理）
   - 视频：mp4/webm/mov/m4v，单个 ≤ 200MB（上传时会自动转码压缩，不用自己处理）
3. 填写标题、正文、选择**频道分类**
4. **打标签**：`#标签` 形式，可加多个——标签是推荐和相关推荐的重要依据，建议认真打
5. **草稿箱**：没写完可以「存草稿」，之后在「草稿箱」恢复继续编辑
6. 发布后进入**内容审核**，管理员定级后才对他人可见（审核通过会收到通知）

### 内容等级说明（管理员定级）

| 等级 | 含义 | 你看到的效果 |
|---|---|---|
| 🟢 绿 | 优质内容 | 首页推送 + 自由浏览 |
| 🟡 黄 | 一般内容 | **首页正常展示** + 自由浏览 |
| 🔴 红 | 敏感内容 | 首页/搜索/主页均展示但**封面模糊 + 「敏感」标记**，点进详情需点击「我已知晓，继续查看」才解除；未登录用户看不到 |
| 驳回 | 不符合规范 | 作者收到通知，可修改后重新发布 |

> 说明：**红黄绿三种等级的笔记都会出现在首页**（「推荐」和「最新」频道均可见）。红标内容对未登录访客隐藏。

## 五、笔记详情与互动

- **点赞 / 收藏**：卡片或详情页点图标即可（收藏后可到「我的收藏」查看）
- **评论**：支持**楼中楼回复**（回复某条评论）、**评论点赞**、按「最新/最热」排序
- **浏览量**：每篇笔记详情页显示被浏览次数
- **相关推荐**：详情页底部会展示与当前笔记**标签相关的其他笔记**（按标签匹配，不是乱推）
- **分享**：复制笔记链接，发给同局域网的朋友可直接打开
- **作者操作**：自己的笔记可以「置顶 / 编辑 / 删除」

---

## 六、个人主页

- 进入方式：点任意用户的头像/昵称，或导航栏自己的头像
- **资料编辑**：头像、昵称、简介可随时修改
- **用户号**：每个用户有一个 8 位用户号（大写字母+数字，终身不变），主页可**复制**——这是**加好友用的身份标识**
- **统计**：笔记数、获赞数、关注数、粉丝数
- **笔记 / 收藏**：两个 Tab 切换查看
- **关注 / 粉丝**：详情页有列表入口；关注后可在首页「关注」频道看 TA 的动态
- **官方认证**：可在主页申请官方认证（提交认证材料说明），管理员审核通过后展示官方标识

---

## 七、搜索与标签

- **笔记搜索**：支持按**标题 / 标签 / 作者昵称**
- **用户搜索**：支持按**昵称 / 用户名 / 8 位用户号**，结果区显示用户卡片（可直接进入主页、加好友、发私信）
- **标签聚合**：点任意笔记下的 `#标签`，查看该标签下的全部笔记

---

## 八、社交功能

### 好友系统
1. 在对方主页点「添加好友」（需要对方**用户号**，主页可复制）
2. 对方收到请求通知 → 接受 / 拒绝
3. 成为好友后可在「好友列表」管理（删除好友等）

### 私信（站内信）
- 顶栏信封图标进入，未读消息有红点
- 支持一对一对话：会话列表 / 聊天窗 / 回车发送 / 自动已读
- 个人主页有「私信」按钮可直达
- 单条消息最多 500 字

### 消息通知
- 顶栏铃铛 + 未读红点
- 被赞、被收藏、被评论、被回复、被关注都会收到通知
- 笔记审核通过/驳回也会通知作者
- 支持单条已读、全部已读

---

## 九、举报

- 笔记详情页 / 评论区可以对**违规内容举报**，填写理由
- 管理员在管理后台「举报管理」查看，可**删除被举报内容**或**忽略**
- 同一内容重复举报会提示（防止滥用）

## 十、管理后台（管理员专用）

浏览器打开 `http://localhost:8099/admin`，用管理员账号登录。

### 概览看板
用户总数、待审核用户/笔记、内容分布等实时统计。

### 1. 用户审核
新注册用户在此**通过 / 拒绝**。通过后才能登录。

### 2. 内容审核（红黄绿定级）
对每篇待审核笔记**定级**：🟢 绿（首页推送）/ 🟡 黄（不进首页）/ 🔴 红（敏感，模糊封面）/ **驳回**；已通过的笔记可随时**改级**或**下架**。

### 3. 用户管理

| 操作 | 说明 |
|---|---|
| **批量创建用户** | 文本框每行 `用户名 密码 昵称`，一次创建多个；可勾选统一设为「官方认证」 |
| **重置密码** | 输入新密码（至少 6 位）重置该用户密码；**重置后该用户所有旧登录立即失效** |
| **重置为 000000** | 直接将该用户密码重置为 `000000`（应急用，点前有确认框；同样会踢掉旧登录） |
| **官方认证** | 通过 / 取消认证申请，或直接开关官方认证标识 |
| **禁用** | ⚠️ 永久性操作：该用户无法登录，**其已发布内容也全部下架**（含 30 天宽限期自动清理，见下） |
| **封锁** | 临时封号：输入小时数（默认 24，快捷 1/24/168/720）。封锁期间该用户**无法登录**（登录时提示"账户已被封锁"）、旧登录失效；**已发布内容保持正常展示、不下架**；**到期自动解封** |
| **解封** | 对已封锁用户解除封锁（也可封锁时输入 0 解除） |

> 管理员账号自己**不可被封锁/禁用**（界面无按钮，后端也拒绝）。

### 4. 笔记管理
- **下架**：笔记从所有地方消失（作者收到通知），进入 30 天宽限期
- **恢复 / 永久删除**：宽限期内管理员可恢复或永久删除
- **清理旧下架**：永久清理超过 N 天（默认 30 天）的下架笔记（含其图片视频文件，不可恢复）
- 支持按状态筛选（全部/待审核/已发布/已下架等）

### 5. 举报管理
查看举报详情 → **删除被举报内容** 或 **忽略**。

### 6. 评论管理
删除违规评论。

## 十一、数据与存储（使用层面）

- **数据文件**：全部在 `data/` 目录（用户、笔记、评论、点赞等 JSON 文件）；上传的图片视频在 `uploads/` 目录
- **备份**：想备份整个社区数据，直接复制 `data/` 和 `uploads/` 两个文件夹即可；恢复时放回原位置重启服务
- **图片自动压缩**：用户上传图片时系统会自动优化（长边超 1600px 自动缩小、转成更省空间的格式），**从源头控制存储占用**，用户无需任何操作；gif 动图 / webp 会原样保留
- **视频自动转码**：上传视频时若服务器装有 ffmpeg，会自动转成 H.264+AAC 的 720p mp4（实测约省 80%+ 体积）；未装 ffmpeg 或转码失败时原样保存，不影响使用
- **清空数据**：想完全重置（回到空白状态），停止服务后清空 `data/*.json` 内容和 `uploads/` 文件即可；下次启动自动重建管理员账号（admin/admin123）

## 十二、常见问题（FAQ）

**Q1：忘记密码了怎么办？**
找管理员：管理后台 → 用户管理 → 该用户「重置为 000000」或「重置密码」自定义一个新密码。重置后对方旧登录会失效，需用新密码重新登录。

**Q2：登录提示"账号已被封锁，请于 xx 后重试"？**
管理员对你做了**临时封锁**（封号）。到提示的时间后自动解封；有异议可联系管理员提前「解封」。封锁不影响你已发布的内容。

**Q3：提示"账号审核未通过"？**
注册后需管理员审核；被拒（禁用）后无法登录。可联系管理员。

**Q4：图片上传失败？**
检查格式（jpg/png/gif/webp）和大小（单张 ≤10MB）。视频上限 200MB。

**Q5：手机/其他电脑打不开？**
确认在同一局域网（同一 WiFi/路由器）；用启动时打印的局域网地址 `http://192.168.x.x:8099` 访问，不是 localhost。

**Q6：端口被占用？**
`PORT=9000 ./start.sh` 换端口启动。

**Q7：数据会丢吗？**
不会。所有操作实时落盘，正常停止（`./start.sh stop`）时会完整保存。建议定期备份 `data/` 和 `uploads/`。

**Q8：不想让别人注册？**
注册需要管理员审核才能登录，不审核就等于关闭注册。也可以在管理后台管理已注册用户。

**Q9：性能怎么样？能支持多少人同时用？**
实测参考（1000 篇笔记、普通 Mac）：
- **500 台设备同时请求**（约等于 500 人在线的高峰瞬间）：全部成功、零失败，最慢的请求约 40ms
- 模拟 500 台设备同时「打开应用」（首页 → 信息流 → 笔记详情，共 1500 个请求）：**0.2 秒全部处理完成**
- 500 并发压力下：信息流 ~6,600 次/秒、笔记详情 ~10,000 次/秒、静态页面 ~37,500 次/秒
- 内存占用：500 并发峰值约 120MB，平时仅 20~30MB（16GB 内存的电脑占比不到 1%）
- 日常使用（几十到几百人、几千到几万篇笔记）性能余量充足，响应为毫秒级

**Q10：想测试一下性能？**
项目自带压测脚本：`scripts/bench.js`，启动服务后运行即可查看各接口的吞吐与延迟。
