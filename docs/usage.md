## 一、快速开始

### 1.1 启动服务

在项目文件夹（sujian）里执行：

```bash
./start.sh            # 启动（自动编译 + 后台常驻）
./start.sh restart    # 重启
./start.sh stop       # 停止
./start.sh status     # 查看运行状态
```

启动后控制台会打印访问地址：

```
素见已启动 ✓
  本机:   http://localhost:8099
  局域网: http://192.168.x.x:8099      ← 同一 WiFi/网线下的手机、电脑用这个打开
```

- 默认端口 **8099**；改端口三种方式（优先级从高到低）：
  - `./start.sh --port 9000` 或 `./start.sh --port 9000 restart`
  - `PORT=9000 ./start.sh`
  - 直接运行二进制：`./sujian-server --port 9000`
- 服务**后台常驻**，关闭终端不影响；日志在 `data/sujian.log`
- **路径已相对二进制**：把整个文件夹移到任何位置都能用（`data/`、`uploads/`、`public/` 都以二进制所在目录为基准解析）
- 本机访问 `http://localhost:8099`，同一局域网的手机/电脑访问 `http://<本机IP>:8099`

### 1.2 预置管理员

首次启动会自动创建管理员账号：

| 项 | 值 |
|----|-----|
| 用户名 | `admin` |
| 密码 | `admin123` |
| 地址 | `http://localhost:8099/admin` |

> 管理员密码可改：在 `main.go` 顶部修改 `AdminPass` 后重启；登录后在个人主页也可自己修改（见 8.5）。

### 1.3 我该用什么账号登录？

- **管理员**：管理整个社区（审核、定级、封禁等，见第十章）
- **普通用户**：需要**注册 → 管理员审核通过**后才能登录（见 2.1）

## 二、账号与登录

### 2.1 注册（需要管理员审核）

1. 打开 `/register` 注册页
2. 填写：用户名（2-20 位，支持字母/数字/下划线/中文）、昵称（可选，默认同用户名）、密码（至少 6 位）
3. 提交后账号状态为**待审核**，页面提示"等待管理员审核"
4. 管理员在后台「用户审核」通过后，你才能登录

> 用户名不可重复；昵称最长 24 字，简介最长 120 字。

### 2.2 登录 / 退出

- 打开 `/login`，输入用户名密码登录
- 登录状态保持 **30 天**（关闭浏览器也不用重新登录）
- 顶栏头像菜单 → 「退出登录」

### 2.3 修改密码（自己改）

> ✅ 此功能已上线。之前只有管理员能改密码，现在每个用户都能自己改。

1. 登录后进入**个人主页**（顶栏头像 → 「个人主页」）
2. 点击「**修改密码**」按钮
3. 输入旧密码 + 新密码（至少 6 位）+ 确认新密码
4. 确认修改成功后：**所有已登录的设备都会被登出**，需要用新密码重新登录

安全提示：修改成功后旧会话立即失效——如果密码疑似泄露，改完后其它设备都会被踢下线。

### 2.4 忘记密码了怎么办？

素见没有"找回密码"功能（局域网小社区，无邮箱/短信）。请找**管理员**在后台「用户管理」→ 该用户操作列 → 「重置密码」或「重置为 000000」，重置后告知你新密码，登录后建议立即自己改成新的（见 2.3）。

### 2.5 查看自己的登录密码

> ✅ 个人中心可查看自己的密码（管理员在后台也能看到所有用户的密码）。

- **本人**：个人主页 → 用户信息区显示「登录密码：••••••••」，点「**显示**」查看明文、点「隐藏」遮住
- **管理员**：管理后台 → 「用户管理」表格有「**密码**」列，可查看/点击复制任意用户密码
- **说明**：
  - 只有**本人**和**管理员**能看到密码，其他用户看你的主页不会显示
  - 密码为**加密存储**（哈希），系统无法还原历史密码——**之前注册/重置的账号密码列显示"—"**；只有**下次设置密码时**（注册新用户/管理员重置/自己修改）才会记录明文副本
  - 如果想让自己/别人的旧账号密码可见：管理员「重置密码」一次即可（重置后明文可见）

> ⚠️ 明文密码副本便于局域网内管理，但相当于"密码明文可查"——请仅在可信的小范围内使用。

## 三、首页与信息流

打开首页 `http://localhost:8099`，顶部是频道栏，下面是瀑布流卡片。

### 3.1 频道与排序

| Tab | 作用 |
|-----|------|
| **推荐** | 综合排序；已登录时按**你的兴趣**智能推荐（见 3.3） |
| **最新** | 按发布时间倒序 |
| **关注** | 只看你关注的人发的笔记 |
| **分类频道**（美食/穿搭/旅行/数码/生活…） | 只看该分类 |

每个分类下都有「综合 / 最新」两种排序可切换。

### 3.2 瀑布流卡片

- 首页卡片按**最短列算法**自动排布（宽屏 4 列 / 平板 2 列 / 手机 1 列），窗口缩放自动重排
- 卡片上显示：**作者昵称、标题、标签、点赞数 ♡、收藏数 ☆、评论数 💬、内容等级色点**（绿/黄/红）
- 视频卡片鼠标悬停会**静音预览**播放；点卡片进详情
- 「加载更多」按钮追加下一页

### 3.3 智能推荐（"为你推荐"）

参考小红书的推荐思路，系统会从你的**点赞、收藏、评论、发布、关注**行为里学习你的兴趣标签，然后给你推荐重叠标签的热门内容：

- 你的互动越多（点赞/收藏/评论），推荐越准
- 新用户没有历史行为时，自动退化为"热度 + 新鲜度"排序（冷启动）
- 推荐会做**多样性打散**，不会全是同一类内容

> 想看到更合口味的推荐：多点赞、多收藏、多评论你感兴趣的内容即可。

### 3.4 内容等级（红黄绿）

每篇笔记发布后由管理员审核定级，等级用卡片左上角的**色点**标识：

| 等级 | 含义 | 展示 |
|------|------|------|
| 🟢 绿 | 普通内容 | 正常展示 |
| 🟡 黄 | 一般内容 | 首页正常展示（不进推荐首位） |
| 🔴 红 | **敏感内容** | 封面**模糊** + 「敏感」标记；点进详情页需点击「我已知晓，继续查看」；**未登录用户看不到** |

## 四、发布笔记

### 4.1 图文笔记

1. 顶栏「**发布**」按钮（或个人主页「+ 发布」）进入发布页
2. **图文模式**：可一次上传多张图片（jpg/png/gif/webp，单张 ≤10MB）
3. 填写：标题（≤60 字）、正文（≤10000 字）、标签（#开头，最多 10 个，每个 ≤20 字）、分类
4. 点「发布」

### 4.2 视频笔记

- **视频模式**：上传一个视频（mp4/webm/mov/m4v，≤200MB）
- 发布时会自动截取视频**第一帧**作为封面
- 视频会被自动转码压缩（720p，省 80% 以上体积），上传慢一点是正常的

### 4.3 草稿箱（存草稿）

- 发布页编辑到一半，点「**保存草稿**」
- 之后从「草稿箱」（顶栏头像菜单）随时**恢复编辑**或删除草稿
- 草稿只在**本账号**可见

### 4.4 发布后要审核

- 新笔记发布后状态为「**审核中**」，只有你自己能看到（个人主页有"审核中"标记）
- 管理员在后台「内容审核」定级（绿/黄/红）或**驳回**后：
  - 通过 → 按等级展示（见 3.4）
  - 驳回 → 笔记标记「未通过」，你会收到通知；**修改后重新提交**会再次进入审核

### 4.5 编辑 / 置顶 / 删除自己的笔记

进入自己的笔记详情页：

| 操作 | 说明 |
|------|------|
| **编辑** | 修改标题/正文/标签/分类/封面。**编辑后笔记会重新进入审核**，重新定级后才对其他用户可见 |
| **置顶** | 在个人主页置顶展示（最多同时置顶多篇，置顶优先排前面） |
| **删除** | 永久删除，笔记、互动、评论、上传的图片视频一并清理，**不可恢复** |

## 五、互动：点赞 / 收藏 / 评论 / 关注

### 5.1 点赞与收藏

- **点赞** ♡：详情页左侧按钮，点一下点赞、再点取消；自己不能给自己笔记"制造"互动吗？可以点，但**不会收到自己的通知**（通知里不会出现自己）
- **收藏** ☆：收藏后可在**个人主页 → 收藏 Tab** 查看；再点取消收藏
- 数字由**服务器权威统计**：多设备同时操作不会显示错乱，点完立即刷新数字

### 5.2 评论（楼中楼）

- 详情页底部评论框直接发评论（≤500 字）
- 点某条评论的「回复」可**楼中楼回复**；回复时自动 @ 对方昵称
- 评论支持**最新 / 最热**两种排序（最热按回复数）
- 每条评论可以**点赞**；评论作者本人或管理员可以**删除**
- 自己发布的笔记收到评论/回复会有通知

### 5.3 关注 / 粉丝

- 在他人主页点「+ 关注」/「已关注」切换
- 关注后：首页「关注」Tab 看到 TA 的新笔记；TA 被关注会收到通知
- 关注/粉丝列表：个人主页统计数字可点进 `/followers` 查看
- 不能关注自己

### 5.4 分享

详情页「分享」按钮复制笔记链接，粘贴给局域网里的朋友即可打开（同一网络内）。

### 5.5 举报

- 笔记详情页或评论上可「**举报**」，填写理由后提交
- 管理员在后台「举报管理」处理：**删除被举报内容**或**忽略**
- 同一内容重复举报会提示

## 六、浏览量是什么

- 每篇笔记显示「N 浏览」，表示被多少人次看过
- **在哪触发**：首页瀑布流卡片**曝光**即计入（别人刷到你就算一次浏览）、进入**详情页**也计入
- **去重**：同一账号对同一篇笔记 **30 分钟内只计 1 次**——反复刷新不会虚增
- **作者本人**浏览自己的笔记**不计入**（防止自己刷自己）
- 数据真实落盘（节流写盘 + 退出时兜底），不会丢

> 想让浏览量涨起来：让不同的人多看几篇笔记。自己刷新不会刷出浏览量的。

### 6.1 我的浏览历史（历史记录）

> ✅ 每个登录用户都有自己的「历史记录」，并且可以自己管理。

- **怎么记**：你**打开看过的笔记**会自动记入「我的历史」（浏览自己的笔记不计入）
- **去重**：同一篇笔记只保留一条，反复看会更新到最前
- **上限**：每用户最多保留 **200 条**，超出自动淘汰最旧的
- **在哪看**：个人主页 → 「**历史**」Tab，按最近浏览倒序展示（封面/标题/看过时间/该笔记数据）
- **怎么管理**：
  - 每条右侧「×」**移除单条**
  - 列表上方「**清空历史**」一键清空（有二次确认）
- **已删除/下架的笔记**不会出现在历史里（自动跳过）

## 七、搜索与标签

### 7.1 搜索笔记

顶栏搜索框，支持：

- **标题**关键词
- **标签**（如搜 `咖啡` 能命中 #咖啡）
- **作者昵称**

### 7.2 搜索用户

在搜索结果页，还能搜**用户**（昵称/用户名/8 位用户号），结果区会显示用户卡片，点进主页可关注/私信。

### 7.3 标签聚合页

点击任意笔记上的 `#标签`，进入该标签下所有笔记的聚合页（瀑布流）。

### 7.4 8 位用户号

每个用户有一个 **8 位大写字母+数字的唯一用户号**（如 `Y2QFKTYZ`）：

- 展示在个人主页，可一键**复制**
- 别人可用它来**精确添加你为好友**（见 9.1）
- 也可在用户搜索里直接搜用户号找到你

## 八、个人主页

进入方式：顶栏头像 → 「个人主页」；或点任何人的头像/昵称。

### 8.1 看别人的主页

- 头像、昵称、简介、加入时间、用户号
- 统计：笔记数 / 获赞 / 关注 / 粉丝（可点进列表）
- 按钮：关注 / 加好友 / 私信
- 官方认证标识（蓝标，见 8.4）

### 8.2 看自己的主页

额外有：

- 「**编辑资料**」：改昵称（≤24 字）、简介（≤120 字）、换头像（上传后保存生效）
- 「**修改密码**」（见 2.3）
- 「**+ 发布**」按钮
- 「笔记 / 收藏 / **历史**」三个 Tab 切换（历史 = 浏览历史，见 6.1）
- 自己可见自己**待审核 / 未通过**的笔记（带状态标记）

### 8.3 统计口径

- 笔记数：已发布数量
- 获赞：你所有笔记收到的赞总和
- 关注 / 粉丝：可点击进入列表页

### 8.4 官方认证（蓝标）

普通用户可以**申请官方认证**：

1. 个人主页点「申请官方认证」
2. 填写认证材料说明（如机构/工作室名称、资质介绍），可上传证明材料图片
3. 管理员在后台审核通过后，你的主页和笔记旁显示**蓝色官方认证标识**；被拒可重新申请

### 8.5 修改密码入口汇总

个人主页 → 「修改密码」（详见 2.3）。管理员同样适用。

## 九、社交：好友 / 私信 / 通知

### 9.1 好友系统

- **加好友**：在对方主页点「+ 加好友」，需要对方的 **8 位用户号**（也可用用户号在好友页直接添加）
- **请求流程**：发出请求 → 对方接受/拒绝 → 成为好友；双方都会收到通知
- **好友列表**：顶栏头像 → 「好友」；可查看请求、删除好友
- 好友关系是**双向确认**的

### 9.2 私信（站内信）

- 顶栏**信封图标**进入私信页；有未读消息时信封带红点
- 从任意用户主页点「私信」直达会话
- 支持：会话列表 / 聊天窗 / **5 秒自动刷新**（对方回消息你最多等 5 秒）/ Enter 发送 / 自动已读
- **发文字**：单条 ≤500 字
- **发任意文件**：输入栏唯一的「**传输文件**」按钮选择文件，**单次 ≤300MB**，图片/视频/文档/压缩包等均可：
  - 图片 → 聊天窗直接显示缩略图
  - 视频 → 聊天窗直接在线播放
  - 其他文件 → 文件卡片（显示文件名+大小，可下载）
  - 会话列表摘要显示「[图片]/[视频]/[文件]」
- 页面切到后台自动暂停刷新，回前台恢复

### 9.3 消息通知

- 顶栏**铃铛图标**：红点 = 未读
- 会收到：**被点赞 / 被收藏 / 被评论 / 被回复 / 被关注**、**笔记审核通过 / 被驳回**、好友请求、官方认证结果
- 支持单条已读、全部已读；删除笔记/评论时相关通知自动清理

## 十、管理后台（管理员专用）

地址 `/admin`，只有管理员能进（普通用户访问会跳回首页）。左侧导航各模块：

### 10.1 概览

社区数据看板：用户总数/待审核、笔记数/待审核、绿黄红各等级数量、评论/点赞总数。

### 10.2 用户审核

处理注册申请：**通过** / **拒绝**。通过后该用户才能登录。

### 10.3 内容审核

处理待审核笔记：

- **定级**：绿（正常）/ 黄（一般）/ 红（敏感，模糊+确认展示）
- **驳回**：笔记不展示，作者收到通知
- 已通过的笔记可随时**改级**

### 10.4 用户管理

| 操作 | 说明 |
|------|------|
| **批量创建用户** | 文本框每行 `用户名 密码 昵称`，可勾选「官方认证」统一标记；创建即 active 可直接用 |
| **查看密码** | 表格「密码」列显示该用户明文密码（点击复制）；历史账号显示"—"（旧数据无明文，重置一次密码后可见） |
| **重置密码** | 自定义新密码；重置后该用户所有会话立即失效（强制重新登录） |
| **一键重置为 000000** | 快捷重置为固定密码，适合临时给成员开账号 |
| **官方认证** | 审核用户的官方认证申请（通过/拒绝） |
| **禁用** | 账号变为禁用：**其已发布笔记自动从所有页面消失**（封号即下架），管理员仍可查看 |
| **封锁 / 解封** | 临时封锁账号：输入小时数（默认 24，快捷 1/24/168/720）；封锁期间无法登录、所有操作被拒，**已发布内容保持展示**；到期自动解封。管理员不可被封 |

### 10.5 笔记管理

- 查看所有笔记（含待审核/已下架）
- **下架**：笔记从所有页面消失（软删除，30 天宽限期）
- **恢复**：宽限期内可恢复上架
- **永久删除**：彻底删除（含互动/评论/媒体文件，不可恢复）
- **清理旧下架**：一键批量清除超过 N 天（默认 30）的下架笔记

### 10.6 评论管理

查看全站评论，可**删除**任何违规评论（级联删除其回复）。

### 10.7 举报管理

查看举报列表（目标/理由/举报人），处理：**删除被举报内容**或**忽略**。

## 十一、内容治理机制

| 机制 | 行为 |
|------|------|
| **红标敏感内容** | 管理员定级为红的内容：封面模糊 + 进入需确认；未登录不可见 |
| **禁用账号** | 被禁用户的笔记立即从首页/搜索/标签/主页/直链消失（管理员仍可见），恢复启用后内容自动回来 |
| **下架宽限期** | 下架笔记保留 30 天；期间可恢复或永久删除；超期可在后台一键清理 |
| **临时封锁** | 封锁期间账号无法登录、会话失效；**内容保持展示**；到期自动解封 |
| **改密踢会话** | 管理员重置密码或用户自己改密码后，该用户所有设备立即下线 |

## 十二、上传与存储

### 12.1 图片

- 支持 jpg/jpeg/png/gif/webp，单张 ≤10MB
- 上传自动优化：长边超过 1600px 自动等比缩小；不透明图转 JPEG（省体积），透明图保留 PNG，动图原样保留

### 12.2 视频

- 支持 mp4/webm/mov/m4v，单个 ≤200MB
- 有 ffmpeg 时自动转码压缩（720p H.264），实测省 80% 以上体积；≤30MB 的视频才转码（避免发布卡顿），更大的原样保存

### 12.3 数据与备份

- 所有数据在 `data/*.json`（用户/笔记/评论/点赞/收藏/关注/通知/草稿/好友/私信等）
- 上传文件在 `uploads/<用户ID>/`
- **备份 = 复制这两个文件夹**；恢复 = 放回原处重启
- 数据实时原子落盘，正常/异常退出都不丢

## 十四、常见问题 FAQ

**Q1：注册后登录提示"待审核"？**
管理员还没审核。等管理员在后台「用户审核」通过后即可登录。

**Q2：忘记密码了怎么办？**
没有自助找回。找管理员重置（后台 → 用户管理 → 重置密码 / 重置为 000000），登录后自己改一个新密码。

**Q3：怎么改自己的密码？**
个人主页 → 「修改密码」→ 输入旧密码 + 新密码。改完所有设备会下线，用新密码重新登录。

**Q4：我发布的笔记别人看不到？**
新笔记默认进入**待审核**，管理员「内容审核」定级后才会展示。被驳回的话修改后重新提交即可。

**Q5：首页卡片上 ☆（星形）的数字是什么？**
是**收藏数**；♡ 是点赞数，💬 是评论数。三者的数据都是真实的服务器统计数据。

**Q6：浏览量一直 0 / 不涨？**
浏览量只在**别人**浏览时计入（作者本人不计），且同一账号 30 分钟内同一篇只计 1 次。让其他账号/设备打开你的笔记就会涨。

**Q6.1：我打开过的笔记在哪里看？怎么删？**
个人主页 → 「**历史**」Tab：按最近浏览倒序展示你看过的笔记；每条可「×」移除，上方可「清空历史」（有二次确认）。最多保留 200 条，已删除的笔记不会显示。

**Q7：上传图片/视频失败？**
检查格式与大小：图片 ≤10MB（jpg/png/gif/webp），视频 ≤200MB（mp4/webm/mov/m4v）。视频大文件转码需等待几秒~十几秒。

**Q8：手机打不开网站？**
手机和电脑连**同一个 WiFi/局域网**，用电脑打印的 `http://192.168.x.x:8099` 地址打开。手机用流量打不开局域网地址。

**Q9：端口被占用 / 想换端口？**
`./start.sh --port 9000`（或 `PORT=9000 ./start.sh`，或直接 `./sujian-server --port 9000`）。改端口后其他用户用对应端口访问即可。

**Q9.1：能不能把整个项目文件夹移到别的位置？**
可以。所有路径（data/、uploads/、public/）都以**二进制所在目录**为基准解析，无论把文件夹从 `/Users/m/Desktop/sujian` 移到 `~/myapp/` 还是 `/tmp/test/` 都直接 `./sujian-server` 即可。

**Q10：数据安全吗？**
数据落盘在 `data/*.json`，每次写操作原子保存、退出兜底；密码用 salt+SHA256 存储。局域网应用强度足够。建议定期备份 `data/` 和 `uploads/` 文件夹。

**Q11：被"封锁"了是什么情况？**
管理员临时封锁账号（可设置小时数）。封锁期间无法登录，到期自动解封；你的内容会正常展示不受影响。如有疑问请联系管理员。

**Q12：素见能支持多少人用？**
实测 500 并发（约 500 台设备同时请求）零失败、最慢请求 ~40ms；1000 篇笔记时各接口 QPS 数千到数万。日常几十~几百人的局域网社区毫无压力。
